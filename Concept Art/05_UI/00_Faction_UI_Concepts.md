# 05_UI — Faction UI Concept Art Planning

**Song of the Shattered Isle** concept art series  
**Category:** User Interface Mockups — Faction Play Experiences, Trait Arbitration, Phase Systems, and Interaction Overlays

**Status:** Generation in progress. First batch (global concepts + Island dashboard) complete — pure artwork mockups following exact planning specs, no text overlays. More batches to follow based on feedback.

---

## Purpose & Scope

This folder plans **beautiful, epic fantasy-style UI concept mockups** (not wireframes or functional specs) for the six playable factions/actors in the game:

1. **Island** (geological, diffuse, epoch-scale)
2. **Animals** (wild, evolutionary, instinct + upgrade driven)
3. **People** (tech tree, cultural, personal-scale advancement)
4. **Structures** (infrastructure lattice, generational projects, Eel-risk tension)
5. **Octopus** (mover, order/control, reef-building, "Octopus of Order" path)
6. **Eel** (lengthener, chaos/openness, interconnection, "Eel Unbound" path)

Each faction needs multiple distinct concepts representing:
- Main dashboard / overview screen
- Signature action or ability selection modes
- Interaction overlays (especially the central **Trait Arbitration** system)
- Path-influenced variants (Order, Chaos, Symphony expressions)
- Special event or endgame views (Kaiju battle toggle, Grand Procession conductor, Symphony fugue state)

**Existing work in folder:**
- `01_Main_World_Map_Mockup.jpg` — Foundational archipelago view. All future UI mockups should feel like they belong in the same visual language (epic painterly fantasy UI, dramatic lighting, rich textures, integrated with the world's art style).

**Total proposed concepts:** ~28–35 high-value mockups (focused, not exhaustive every possible screen).

## Overall UI Visual Language (Critical for Consistency)

All mockups must feel like **concept art of playable screens** in the same universe as the rest of the Concept Art series:

- **Style anchor:** Match the epic painterly fantasy aesthetic of **Mood Image.png** and the existing `01_Main_World_Map_Mockup.jpg`. Dramatic cinematic lighting, rich material textures, turquoise sea accents, ancient wonder, highly detailed.
- **Fantasy UI treatment:** Ornate frames and borders that incorporate animal materials (fur-lined panels, scale-plate edges, feather quill accents, coral/reef motifs, glowing Ancient Diamond inlays, living Wood/Grass elements in Symphony state).
- **Glowing / Transcendent elements:** Ancient tier and Special Animal influence should literally glow or shimmer.
- **Aesthetic direction (updated per feedback):** Shift toward a busier graphic design / illustrated vector-art influenced fantasy UI style. Denser compositions with many more symbolic icons, emblems, buttons, and small visual elements (all icon-only, no legible text or numbers). "Busy is better than clean" — layered panels, icon grids for actions/choices, material tokens, and recurring motifs are encouraged while preserving hand-crafted mythic quality, path expression, and material integration. Zero-text aesthetic (icons/symbols only) remains mandatory.
- **Path expression:** 
  - **Order path** — Rigid geometry, heavy bronze/iron frames, martial banners, controlled symmetry, Octopus coral rigidity.
  - **Chaos / Eel path** — Fluid, tangled, "long" organic lines, bioluminescent edges, overflowing/interconnected elements, slight distortion or "lengthening" effects.
  - **True Symphony / Balance** — Harmonious integration, living hybrid frames (Wood + built elements growing together), rainbow/Special Animal accents, musical resonance motifs (subtle staff lines, vibrating strings, bell forms).
- **No modern flat design.** Everything feels hand-crafted, mythic, slightly worn by time and use.
- **Information hierarchy:** Clear focal points for the current faction's "voice," trait radars/spider charts as recurring visual motif, phase timeline as persistent element.
- **Pure artwork** — These are aspirational mockups. No text, numbers, or legible labels anywhere (zero-text aesthetic with icons/symbols only). Busy, icon-dense layouts preferred over minimal/clean designs. Evocative painted + graphic design representations of screens.

**Recurring UI motifs across all factions:**
- Large central **Trait Radar / Spider Chart** (7 axes: Might, Wisdom, Honor, Wealth, Power, Glory, Blessing) showing current faction profile + comparison ghosts of other factions.
- **Actor State Matrix** (small 6xN grid showing Active/Passive/Dormant + influence values for current phase).
- **Arbitration Voting Chamber** overlay or dedicated screen (multi-round a/b/c/d visualization with weighted tokens, tie re-evaluation flow).
- Material-framed windows (different per faction: coral for Octopus, luminescent stone for Eel, fur/wool for cold-adapted, etc.).
- Subtle background showing the current island or world state (using 02_Islands references for mood).
